# Completely Normal Notepad

> A quiet text editor where deleted words do not disappear.

*Work in progress.*

---

## Overview

Completely Normal Notepad is an experimental writing canvas. Rather than vanishing into the void, deleted fragments rise as ethereal interactive spirits governed by physics, dynamic audio, and ambient curiosities in the periphery.

## Stack

- **Framework**: Next.js (App Router, Turbopack)
- **UI & State**: React 19, TypeScript, Tailwind CSS, Zustand
- **Audio & Physics**: Web Audio API (procedural synthesis), Vector physics simulation
- **Testing**: Vitest

## Getting Started

### Prerequisites
- Node.js 18.17+
- npm

### Installation
```bash
git clone https://github.com/Dr-Ghost7/completely-normal-notepad.git
cd completely-normal-notepad
npm install
```

### Development
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Testing
```bash
npm test
```
